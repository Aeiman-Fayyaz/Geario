## Geario 

Geario serves as a modern vehicle discovery platform highlighting key automotive models and features. It includes sections for featured cars, gallery views, product listings, testimonials, and contact form capabilities.

## 📍 Tech Stack

Geario is built with the following technologies:

- Framework: Tailwind
- Hosting & Deployment: Vercel – instant global deployment and optimization
- Styling: CSS
- Images: Optimized static image assets
